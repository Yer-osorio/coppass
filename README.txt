MISIÓN COPPAS — COMUNIDAD PREPARADA (V3)

1. Extrae este ZIP.
2. Abre la carpeta "COPPAS-Mision-Comunidad-Preparada-v3" en Visual Studio Code.
3. Abre index.html en un navegador (doble clic o Live Server).

CONTROLES
- W A S D / flechas: movimiento.
- E: interactuar.
- Esc: cerrar ventanas.
- En móvil aparecen controles táctiles.

DISEÑO
- Mundo 2D abierto con cámara suave.
- Colisiones por edificios y zonas no transitables.
- Misiones por niveles y zonas que se desbloquean.
- Retos interactivos de kit, plan familiar, mapa y articulación.
- El siguiente nivel requiere superar el reto de conocimiento del nivel anterior.
- Todo funciona localmente con HTML, CSS y JavaScript, sin librerías externas.

CONTENIDO
El juego está basado en el material formativo COPPAS trabajado: conocimiento de la realidad, organización comunitaria, planeación, recursos, asistencia, articulación y preparación ante emergencias.
